# Restaurant Analytics Project | MySQL

## 📌 Project Overview
This project focuses on designing, building, and analyzing a relational database for a company that manages restaurant memberships and tracks customer orders using **MySQL**[cite: 8, 12].

## 🗄️ Database Schema
The database consists of 10 interconnected tables linked via Primary and Foreign Keys:
- `cities`, `restaurants`, `restaurant_types`[cite: 8, 9]
- `members`, `monthly_member_totals`[cite: 8, 9]
- `orders`, `order_details`[cite: 8, 9]
- `meals`, `meal_types`, `serve_types`[cite: 8, 9]

## 🛠️ Tools Used
- **MySQL**[cite: 12]
- **dbdiagram.io** (Database Schema Design)
